# 新建简历默认模板（校招行政专员）设计说明

日期：2026-10-17
状态：已实现并通过验收（17/17）

## 目标

新建简历时不再生成空白简历，而是默认填充一份「校招行政专员简历模板」，
新人直接在此基础上改内容即可使用。

## 方案

- 模板从「由种子简历派生」改为**固定代码常量**：新增 `server/defaultTemplate.js`
  （`buildDefaultTemplate()`），创建简历时深拷贝并写入新 `resumeId`。
- 删除原 `server/data/_template.json` 及 `buildBlankTemplate / loadTemplate / ensureTemplate`
  等派生逻辑，避免模板内容随种子简历变化。
- 模板中**没有内容的模块设为 `visible: false`**（报考信息、工作经历、项目经验、荣誉证书、
  兴趣爱好、自定义模块），避免预览出现一排空标题；用户可在编辑区点模块名称上的圆点随时启用。
- 有内容的模块顺序：求职意向 → 教育背景 → 实习经历 → 校园经历 → 技能特长 → 自我评价，
  `moduleSort` 同步调整。

| 求职意向 行政专员、现居北京市海淀区 | `yixiang.data.job=行政专员`、`yixiang.data.city=北京`（页面无「现居城市」字段，城市归入意向城市） |
